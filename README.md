# 🚀 Sobre el Proyecto

El **Manual de Usuario de iMirly** es una plataforma web estática diseñada específicamente para centralizar toda la documentación, guías de uso y tutoriales visuales de la aplicación **iMirly**. Este sitio sirve como el punto de referencia principal para que los usuarios aprendan a navegar por la app, desde el registro inicial hasta la gestión avanzada de servicios.

✨ **Características principales:**

*   🖥️ **Diseño Moderno:** Interfaz limpia construida con la fuente **Inter** y la librería **Phosphor Icons**.
*   📱 **Totalmente Responsivo:** Adaptado para una lectura cómoda desde dispositivos móviles o escritorio.
*   📸 **Guía Visual:** Incluye capturas de pantalla detalladas de cada flujo de la aplicación (Splash, Home, Registro, etc.).
*   🧭 **Navegación Sticky:** Menú persistente con efectos de desenfoque (**glassmorphism**) para un acceso rápido a las secciones.
*   ⚡ **Rendimiento Óptimo:** Implementado como una Simple Page Application (SPA) para transiciones suaves y carga instantánea.

# 🧠 Contexto del Proyecto

Este manual forma parte del ecosistema de **iMirly**, un proyecto desarrollado como parte de la formación en **DAM en NDT NewDigitalTalent · Granada**. El objetivo es proporcionar una experiencia de usuario (UX) de alta calidad, asegurando que la curva de aprendizaje de la aplicación principal sea lo más baja posible mediante una documentación accesible y profesional.

# 🛠️ Stack Tecnológico

| Tecnología | Uso |
| :--- | :--- |
| **HTML5** | Estructura semántica del manual y contenido. |
| **CSS3** | Estilado avanzado, Flexbox, y variables CSS personalizadas. |
| **JavaScript** | Manejo de eventos de navegación y efectos visuales de scroll. |
| **Phosphor Icons** | Iconografía minimalista y escalable. |
| **Google Fonts** | Tipografía Inter para mejorar la legibilidad. |

# ⚙️ Instalación y Uso

Al ser una página web estática, no requiere de compilación ni servidores complejos.

1.  **Clona el repositorio:**
    ```bash
    git clone https://github.com/iMirly/Manual-de-usuario.git
    ```
2.  **Abre el archivo principal:**
    Navega a la carpeta del proyecto y abre `index.html` en cualquier navegador moderno (Chrome, Firefox, Edge).
3.  **Despliegue rápido:**
    Puedes usar servicios como **GitHub Pages** para hospedar este manual de forma gratuita apuntando a la rama `main`.
